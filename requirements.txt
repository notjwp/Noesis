# Pinned dependencies for personal-agent.
#
# Exact pins throughout, deliberately: this project's headline number is a
# measurement, and an unpinned dependency silently changes what was measured.
#
# `pyproject.toml` remains the source of truth for the agent's own runtime
# dependencies. The pins below MUST match it; if they drift, pyproject wins.
# Recorded here as well because the container installs by list, not by package,
# and because two of the three groups below have no other declared home.
#
# The agent installs natively (`sh scripts/install.sh`, which reads pyproject).
# This list is for the CONTAINER, where scored runs happen: the image installs
# by list, and the fixture group below has no other declared home.
#
#   pip install -r requirements.txt

# --- agent runtime -----------------------------------------------------------
# Mirrors [project.dependencies] in pyproject.toml.
# Two provider SDKs, not one: the second implementation is what earns
# agent/provider.py its own module, and either can be selected at runtime.
anthropic==0.122.0
langgraph==1.2.11
langgraph-checkpoint-sqlite==3.1.1
openai==3.2.0

# --- MCP (Phase L) -----------------------------------------------------------
# The client half plus the ONE server this phase ships. Both are installed in the
# image ahead of the /etc/pip.conf line, because that line sets no-index and
# nothing can be installed at run time - which is also the security property: a
# server cannot be introduced mid-run.
#
# mcp is pinned to 1.29.0 and NOT 2.0.0. Measured, not assumed: 2.0.0 fails with
# `ResolutionImpossible`, because mcp-server-fetch declares `mcp<2,>=1.29.0`.
#
# mcp-server-fetch prints "node executable not found, reverting to pure-Python
# mode" on every start. That is expected and deliberate - there is no Node in the
# image, and it degrades from Readability.js to a pure-Python extractor rather
# than failing. Adding a Node runtime is a decision to take on evidence, not on
# the way past.
mcp==1.29.0
mcp-server-fetch==2026.8.18

# --- skills (Phase N) --------------------------------------------------------
# Frontmatter parsing for the agentskills.io SKILL.md format. A real YAML parser
# rather than a hand-rolled key:value split, because `description` is prose and is
# the field retrieval depends on.
pyyaml==6.0.2

# --- tests -------------------------------------------------------------------
# Mirrors [project.optional-dependencies].dev. The unit suite runs with no API
# key, no network, and a read-only root filesystem.
pytest==9.1.1

# --- evaluation fixture runtime ----------------------------------------------
# NOT agent dependencies. These exist so the practice projects and the vendored
# real repositories can run their own test suites inside the sandbox, which has
# no egress and therefore cannot install anything at run time.

# to the versions the scored 0/18 real-repository baseline actually ran against.

#   flask           practice project `add-endpoint`
#   freezegun       real-humanize (time-dependent tests)
#   attrs           real-rich (tests/test_pretty.py collection)

flask==3.1.3
freezegun==1.5.5
attrs==26.1.0
pygments==2.21.0
markdown-it-py==4.2.0
